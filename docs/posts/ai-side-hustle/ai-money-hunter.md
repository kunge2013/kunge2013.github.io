## 项目背后的故事

这个项目由 [@Yangyi](https://twitter.com/intent/follow?screen_name=yangyixxxx) 在 2023 年末整理创建。

2022 年末 ChatGPT 到来后，作者开始用 AI，2023 年初为了实践一个 SEO 工具 + WordPress 导航站模板，把 ChatGPT / Midjourney / StableDiffusion 的教程整理进了网站。

策略简单：**做大众最需要的学习内容**，用一键安装包降低上手门槛。网站先发在即刻，被推特 A 姐转发后在抖音上爆发——博主自发发视频晒网站但不告诉用户是什么，用户在评论区问，视频有流量，博主回答，网站也有流量，**两周 DAU 达到 2 万**。

后来仓库在 X 上被宝玉转发后再次火起来，网站 DAU 回到 1 万。整个项目的核心经验是：**内容生态最重要的是运营，没有好的内容就没了生命力**。

## 一、如何稳妥地开始副业

### 四条建议

| # | 建议 | 核心思路 |
|---|------|----------|
| 1 | **做内容搞流量，而不是做产品去卖** | 搞来流量，流量自然需要产品，找到别人的产品合作促成交就能赚钱 |
| 2 | **做铲子，而不是挖金子** | 卖铲子往往更直接。做产品支持贴牌让大家一起挖金子；自己挖金子就做分销 |
| 3 | **不想花钱，就要花时间** | 花钱跟人买认知然后执行，风险小但要付出成本；不想付出成本就用时间不断试错 |
| 4 | **做资产，而不是卖时间** | 时间不能同时卖出多份就和打工没差别，要累积自己的资产 |

### 一条策略

> **做自媒体流量，抱着平台吃饭**是当下用 AI 做副业最亲民的一条路径。

## 二、AI 技术赚钱思路

### 技术赚钱的几条认知

- **做垂类，而不是做平台**：GPT 套壳那么多，增加一个垂类才能被人知道（桌面版 GPT？自媒体 GPT？AI 女友？）
- **做顺人性的，而不是逆人性的**：做小说就顺人性，搞教育就逆人性
- **从小切入**：想做 Midjourney 绘画站，先做个 Midjourney API 就够了
- **开源赚流量，比闭源挖金子强**：开源时会源源不断收获资源
- **Build in Public**：公开构建会带来极大的公共认同和流量基础
- **Copycat**：欧美到国内，国内到非洲，有信息茧房就有钱赚
- **做国外而非国内**：国外赚美金，避开国内 LLM 审核问题
- **赚有钱人的钱，赚想赚钱人的钱**：这两个人群最好付费

### 5 种已验证的技术赚钱方案

#### 1. 套壳站

GPT / MJ 套壳站，做成 SaaS 或支持私有化部署贴牌，几千块一套卖给想赚钱的小老板。离不开**分销系统**。

#### 2. API 聚合

封装各类 LLM / AI 能力为 API，让开发者免去海外结算和部署转发服务器的麻烦。中间商赚差价，找便宜的 API 账号按比官网低的价格卖。

#### 3. 发卡站

开源发卡站自动卖 GPT 账号，给号贩子提供工具就能赚钱。

#### 4. 聚焦的 AI 工具

AI 写论文、AI 自动自媒体发布、AI 证件照……把 AI 能力聚焦到某一领域或某一人群的特定需求上。**足够聚焦，就会带来力量**。

#### 5. 模型训练

帮甲方做模型训练，国内模型效果可能达不到甲方要求，交付有难度。
