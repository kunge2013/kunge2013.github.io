## 什么是 feynman-learning Skill？

`feynman-learning` 是一个 Claude Code 的 Skill（技能插件），它让 AI 成为你的**费曼学习法教练**。

它不是直接给你答案，而是像一位经验丰富的老师，引导你走完费曼学习法的完整五步流程，帮你真正理解一个知识点，并能用通俗易懂的语言讲给别人听。

> 核心理念：**"学 = 教。教不出来 = 没学会。"**

## 使用流程

### 第一步：提出知识点

告诉 AI 你想学什么，越具体越好：

✅ **好的提问**：
- "用费曼学习法学习 TCP 三次握手"
- "帮我理解 Git 的 rebase 和 merge 的区别"
- "用简单话解释什么是区块链"

❌ **太模糊的提问**：
- "帮我学习计算机科学"（太大）
- "我想懂编程"（太泛）

### 第二步：回答教练的问题

AI 教练会问你几个问题来确认学习目标：

1. **你为什么要学这个？** （准备面试？做项目？给团队分享？）
2. **你之前对这块有多少了解？** （零基础？有一点概念？）
3. **最终讲给谁听？** （完全不懂的外行？有基础的同事？）

### 第三步：跟着教练走完五步

AI 会一步步引导你：

```
🎯 确立目标 → 📚 理解知识 → 🗣️ 输出教授 → 🔍 回顾反思 → ✨ 简化吸收
     ↑                                                          ↓
     └──────────── 循环迭代（卡壳就回来） ───────────────────────┘
```

**关键互动**：

- **🗣️ 输出教授**：你需要自己用通俗的话解释概念（这一步最关键！）
- **🔍 回顾反思**：AI 会标记你解释不清的地方（卡壳点），帮你分析原因
- **✨ 简化吸收**：最终生成一句话总结和通俗易懂的讲解稿

### 第四步：获得学习成果

完成后，你会得到一份**费曼笔记**，包含：

- 一句话解释
- 生活化类比
- 核心要点（3-5 个）
- 你的通俗讲解
- 学习反思

还可以一键保存为博客文章，发布到 `feynman-technique` 分类下！

## 完整示例

### 示例 1：学习"递归"

**你**：用费曼学习法学习递归

**AI 教练**：
> 好的！先确认几个问题：
> 1. 你学递归是为了什么？
> 2. 你之前对递归有多少了解？
> 3. 最终讲给谁听？

**你**：准备面试，之前知道递归就是函数调用自己

**AI 教练**：
> 📚 让我帮你梳理知识结构：
> ```
> 递归（Recursion）
> ├── 定义：函数在执行过程中调用自身
> ├── 两要素：基准情况 + 递归步骤
> ├── 执行过程：调用栈的变化
> └── 注意事项：栈溢出、性能问题
> ```
> 🗣️ 现在假设面试官问"什么是递归？"，请你用自己的话解释一下。

**你**：递归就是函数调用自己，像照镜子一样

**AI 教练**：
> ✅ 类比生动
> ⚠️ 但你没说到"什么时候停下来"。镜子是无限的，但递归必须有终点。
> 能再试一次吗？

**你**：递归就是把大问题拆成同样的小问题，但必须知道什么时候拆到头了

**AI 教练**：
> 🎉 精辟！这就是你的最终版讲解。来做个一句话总结吧？

## Skill 的设计亮点

### 1. 交互式教练模式

不是直接给答案，而是引导你自己走完五步。这样学到的知识才是你自己的。

### 2. 卡壳检测与反馈

AI 会作为"听众"给你反馈：
- 通俗性：有没有用外行能懂的语言？
- 准确性：核心概念是否正确？
- 完整性：有没有遗漏关键部分？
- 类比质量：用的类比是否恰当？

### 3. 第一性原理结合

遇到复杂概念，AI 会帮你用第一性原理拆解：
- 这个知识的基本事实是什么？
- 能不能从这些基本事实重新构建理解？

### 4. 成果输出

最终生成通俗易懂的讲解稿，可以：
- 直接用于面试回答
- 作为团队分享的材料
- 保存为博客文章发布

## 常见问题

### Q：Skill 和普通对话有什么区别？

**普通对话**：你问"什么是递归？"，AI 直接给你答案。

**Skill 引导**：AI 不直接给答案，而是让你自己解释，然后给反馈。这才是真正的学习。

### Q：如果我完全不懂某个概念怎么办？

没问题！Skill 会先帮你搜索资料、整理知识结构，然后再让你尝试解释。卡壳是正常的，这正是学习的开始。

### Q：可以学习非技术类知识吗？

当然可以！虽然示例多是技术概念，但任何知识点都可以用费曼学习法：
- 经济学概念（如"供需关系"）
- 心理学理论（如"认知偏差"）
- 历史事件（如"法国大革命"）
- 任何你想学的东西

### Q：学完后一定要输出文章吗？

不是必须的，但强烈推荐。输出是费曼学习法的核心，写下来或讲给别人听，才能真正检验你是否理解了。
