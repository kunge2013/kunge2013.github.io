# Raycast 全面介绍：功能、特点与快捷键

<!-- [AGC:START] tool=Cc author=fangkun -->

Raycast 是一款专为 macOS 打造的效率工具，它将启动器、搜索、剪贴板管理、窗口控制、脚本执行等功能集于一身，旨在替代 Spotlight 并成为你的日常工作中心。

## 什么是 Raycast？

Raycast 是一个可扩展的启动器（Launcher），它允许你通过快捷键快速访问各种功能。你可以把它想象成一个超级版的 Spotlight，但它能做的远不止搜索文件。

简单来说，Raycast 是一个**统一的工作入口**，让你无需在多个应用之间切换，直接在启动器中完成各种任务。

## 核心功能

### 1. 应用启动与文件搜索

- **快速启动应用**：输入应用名称的前几个字母即可启动
- **文件搜索**：搜索本地文件、文件夹
- **文档搜索**：搜索 PDF、Word、Excel 等文档内容

### 2. 剪贴板历史

- **历史记录**：自动记录复制的内容，随时调用
- **多格式支持**：文本、图片、链接、文件等
- **搜索与筛选**：快速查找历史剪贴板内容
- **固定常用内容**：将常用文本固定在顶部

### 3. 窗口管理

- **窗口布局**：快速调整窗口大小和位置
- **窗口切换**：在不同窗口间快速切换
- **分屏操作**：一键实现多窗口并排

### 4. 扩展系统（Extensions）

- **社区扩展**：数百个官方和社区开发的扩展
- **自定义扩展**：使用 TypeScript/React 开发自己的扩展
- **集成工具**：GitHub、Notion、Linear、Jira、Slack 等
- **脚本命令**：运行 Shell 脚本、Python、Node.js 等

### 5. Snippet（代码片段）

- **文本替换**：输入缩写自动展开为完整文本
- **动态变量**：支持日期、时间、光标位置等动态内容
- **跨应用使用**：在任何应用中都能使用

### 6. Quicklinks（快速链接）

- **自定义搜索**：创建自定义的搜索模板
- **快速访问**：一键打开常用网站或内部工具
- **参数化查询**：支持动态参数传递

### 7. 计算器与单位转换

- **数学计算**：支持复杂的数学表达式
- **单位转换**：长度、重量、温度、货币等
- **实时计算**：在搜索框中直接计算

### 8. 系统控制

- **系统设置**：快速访问系统偏好设置
- **音量控制**：调整音量、亮度
- **网络信息**：查看 IP 地址、网络状态
- **进程管理**：查看和控制运行中的进程

## 特点与优势

### 🚀 极速性能

- **毫秒级响应**：快捷键唤起几乎零延迟
- **本地优先**：大部分功能在本地运行，不依赖网络
- **资源占用低**：优化良好，不会拖慢系统

### 🎨 美观的界面

- **现代设计**：符合 macOS 设计语言
- **主题支持**：明暗主题、自定义配色
- **流畅动画**：交互体验丝滑

### 🔌 高度可扩展

- **扩展生态**：丰富的官方和社区扩展
- **API 开放**：完整的扩展开发文档
- **脚本支持**：支持多种编程语言的脚本

### 🔒 隐私与安全

- **本地处理**：敏感数据不上传云端
- **权限控制**：细粒度的权限管理
- **开源透明**：部分核心代码开源

### ⚡ 工作流集成

- **Hotkeys**：为任何功能设置快捷键
- **Extensions**：与你的工具链深度集成
- **Automation**：自动化重复任务

## 解决什么问题？

### ❌ 传统痛点

1. **频繁切换应用**：在不同工具间来回切换，打断心流
2. **找不到常用功能**：系统设置、剪贴板历史等功能分散
3. **重复性工作**：手动执行重复的操作
4. **信息分散**：剪贴板、书签、笔记等信息散落各处

### ✅ Raycast 的解决方案

1. **统一入口**：一个快捷键访问所有功能
2. **快速访问**：减少点击次数，提升效率
3. **自动化**：用扩展和脚本自动化重复任务
4. **集中管理**：整合各种工具和信息

## 常用快捷键

### 基础操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `⌥ Space` | 打开 Raycast | 默认快捷键，可在设置中修改 |
| `Esc` | 关闭 Raycast | 退出当前界面 |
| `Enter` | 执行操作 | 执行选中的操作 |
| `Tab` | 自动补全 | 补全搜索内容 |
| `↑` / `↓` | 导航 | 在列表中上下选择 |
| `←` / `→` | 切换标签 | 在不同分类间切换 |

### 搜索与导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `⌘ K` | 搜索操作 | 搜索可用的操作 |
| `⌘ ,` | 打开设置 | 进入 Raycast 设置界面 |
| `⌘ Enter` | 执行主要操作 | 执行列表中的第一个操作 |
| `⌥ Enter` | 执行次要操作 | 执行次要操作（如果有） |
| `⌘ I` | 查看详细信息 | 查看选中项的详情 |

### 剪贴板历史

| 快捷键 | 功能 | 说明 |
|--------|------|------|

| `⌘ C` | 复制选中项 | 复制剪贴板历史中的内容 |
| `⌘ Shift C` | 复制并粘贴 | 复制并自动粘贴到当前应用 |
| `⌘ P` | 固定/取消固定 | 固定常用内容到顶部 |
| `⌘ Delete` | 删除选中项 | 从历史中删除 |

### 窗口管理

| 快捷键 | 功能 | 说明 |

| `⌃ ↓` | 窗口最小化 | 最小化当前窗口 |
| `⌃ ←` | 窗口左上象限 | 占据屏幕左上四分之一 |

| `⌃ Shift ←` | 窗口左三分之一 | 占据屏幕左三分之一 |

### Snippet 与 Quicklinks

| 快捷键 | 功能 | 说明 |

### 扩展操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `⌘ Enter` | 执行扩展操作 | 执行选中的扩展命令 |
| `⌥ ⌘ Return` | 查看扩展详情 | 查看扩展的详细信息 |
| `⌘ ,` | 扩展设置 | 打开扩展的设置界面 |

## 自定义快捷键

Raycast 允许你为几乎任何操作自定义快捷键：

1. 打开 Raycast 设置（`⌘ ,`）
2. 进入 "Extensions" 标签
3. 选择要配置快捷键的扩展
4. 点击 "Record Hotkey" 录制新的快捷键

**建议**：
- 使用 `⌥` (Option) 作为主要修饰键
- 避免与系统快捷键冲突
- 为常用功能设置肌肉记忆快捷键
