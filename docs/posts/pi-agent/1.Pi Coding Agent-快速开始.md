## 安装

Pi 以 npm 包的形式分发：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

`--ignore-scripts` 在安装期间禁用依赖生命周期脚本。Pi 在正常的 npm 安装中不需要安装脚本。

### 卸载

使用安装 pi 的包管理器。curl 安装器全局使用 npm，因此 curl 和 npm 安装都通过 npm 卸载：

```bash
# curl 安装器或 npm install -g
npm uninstall -g @earendil-works/pi-coding-agent

# pnpm
pnpm remove -g @earendil-works/pi-coding-agent

# Yarn
yarn global remove @earendil-works/pi-coding-agent

# Bun
bun uninstall -g @earendil-works/pi-coding-agent
```

卸载 pi 会将设置、凭据、会话和已安装的 pi 包保留在 `~/.pi/agent/` 中。

然后在你要让它工作的项目目录中启动 pi：

```bash
cd /path/to/project
pi
```

## 认证

Pi 可以通过 `/login` 使用订阅提供商，或者通过环境变量或认证文件使用 API 密钥提供商。

启动 pi 并运行：

```
/login
```

然后选择一个提供商。内置订阅登录包括 Claude Pro/Max、ChatGPT Plus/Pro (Codex) 和 GitHub Copilot。

### 方式二：API 密钥

在启动 pi 之前设置 API 密钥：

```bash
export ANTHROPIC_API_KEY=sk-ant-...
pi
```

你也可以运行 `/login` 并选择一个 API 密钥提供商，将密钥存储在 `~/.pi/agent/auth.json` 中。

请参阅[提供商](https://pi.dev/docs/latest/providers)了解所有支持的提供商、环境变量和云提供商设置。

## 第一次会话

pi 启动后，输入请求并按回车键：

```
总结这个仓库并告诉我如何运行它的检查。
```

默认情况下，pi 为模型提供四个工具：

- `read` - 读取文件
- `write` - 创建或覆盖文件
- `edit` - 修补文件
- `bash` - 运行 shell 命令

通过工具选项可以使用其他内置只读工具（`grep`、`find`、`ls`）。Pi 在当前工作目录中运行，可以修改那里的文件。如果想要轻松回滚，请使用 git 或其他检查点工作流。

## 给 pi 提供项目说明

Pi 在启动时加载上下文文件。添加一个 `AGENTS.md` 文件来告诉它如何在项目中工作：

```markdown
# 项目说明

- 代码更改后运行 \`npm run check\`。
- 不要在本地运行生产环境迁移。
- 保持响应简洁。
```

Pi 加载：

- `~/.pi/agent/AGENTS.md` 用于全局说明
- 父目录和当前目录中的 `AGENTS.md` 或 `CLAUDE.md`

如果目录包含 `AGENTS.override.md`，Pi 会加载它而不是该目录中的 `AGENTS.md` 或 `CLAUDE.md`。

更改上下文文件后，重启 pi 或运行 `/reload`。

## 常见尝试事项

### 引用文件

在编辑器中输入 `@` 来模糊搜索文件，或在命令行中传递文件：

```bash
pi @README.md "总结这个"
pi @src/app.ts @src/app.test.ts "一起审查这些"
```

可以使用 Ctrl+V（Windows 上为 Alt+V）粘贴图片或文本；图片也可以拖放到支持的终端中。

### 运行 shell 命令

在交互模式下：

```
!npm run lint
```

命令输出会发送给模型。使用 `!!command` 运行命令而不将其输出添加到模型上下文中。

### 切换模型

使用 `/model` 或 Ctrl+L 为当前会话选择模型。在模型选择器中按 Ctrl+S 将突出显示的模型保存为启动默认值。使用 `/thinking` 为当前会话选择思考级别，或在该选择器中按 Ctrl+S 保存启动默认思考级别。使用 Shift+Tab 循环切换思考级别。使用 Ctrl+P / Shift+Ctrl+P 循环切换作用域模型。

### 稍后继续

会话会自动保存：

```bash
pi -c                  # 继续最近的会话
pi -r                  # 浏览以前的会话
pi --name "my task"    # 启动时设置会话显示名称
pi --session <path|id> # 打开特定会话
```

在 pi 内部，使用 `/resume`、`/new`、`/tree`、`/fork` 和 `/clone` 来管理会话。

### 非交互模式

用于一次性提示：

```bash
pi -p "总结这个代码库"
cat README.md | pi -p "总结这段文本"
pi -p @screenshot.png "这张图片里有什么？"
```

使用 `--mode json` 获取 JSON 事件输出，或使用 `--mode rpc` 进行进程集成。
